# AGENTS.md

Follow global AGENTS at ~/.openclaw/codex-global/AGENTS.md

## Repo workflows

- Browser mode: `go run ./cmd/web`
- Desktop dev mode: `cd desktop && go run github.com/wailsapp/wails/v2/cmd/wails@v2.11.0 dev -s`

## Test commands

- Go tests: `go test ./...`
- UI tests: `npm run test:ui`
- UI tests (headed): `npm run test:ui:headed`
- UI tests (debug): `npm run test:ui:debug`
- Mutation tests: `npm run test:mutation`
- Mutation tests with HTML report: `npm run test:mutation:html`

## E2E test environment

- Playwright starts the app with `ORBIT_DATA_DIR=.e2e-data PORT=18101 go run ./cmd/web`
- Base URL is `http://127.0.0.1:18101`
- The E2E run resets `.e2e-data` before startup

## Release commands

- macOS desktop build: `cd desktop && wails build -platform darwin/universal -clean`
- Windows desktop build: `cd desktop && wails build -platform windows/amd64,windows/arm64 -nsis -clean`
- Build outputs are written under `desktop/build/bin`

## Notes

- Prefer targeted mutation runs while iterating on tests:
  `go run github.com/avito-tech/go-mutesting/cmd/go-mutesting@latest --exec-timeout 20 --match '<regex>' .`
- `desktop/build/windows/installer/wails_tools.nsh` is generated by Wails; do not hand-edit it.
